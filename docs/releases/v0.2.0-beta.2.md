# Aegis v0.2.0-beta.2

Status: **Release candidate — prerelease; publication is not authorized by this task**

## What beta.2 is

Beta.2 is the next bounded candidate in the Aegis Control Plane v0.2 line,
distributed as one native Plugin with exactly nine canonical Skills. It
materializes the accepted Verification Productization evidence-contract
hardening, Project State v0.6 capability, repository-identity fail-closed
execution, and immutable/append-only historical integration semantics.

## Changes since beta.1

- Project State v0.6 supports `Bound` and affirmative historical `Absent`
  Gate Decision Binding with deterministic v0.5 → v0.6 migration.
- Integrated occurrence identity remains immutable and corroborating evidence
  is append-only.
- Release packaging and exact-nine Plugin parity are bound to the beta.2
  candidate manifest.

## Boundaries

The repository root `.aegis/**` remains schema v0.5; this candidate does not
claim root v0.6 persistence or real `int-pr82` persistence. No synthetic or
retroactive PR #82 Gate Decision is created. `SERVICE_PROFILE`, rollout
expansion, daemon/agent/runtime service, merge, and publication remain outside
this candidate task.

## Distribution and verification

The candidate Installation Kit is
`aegis-skill-installation-kit-v0.2.0-beta.2.zip` and contains exactly nine
nested Skill archives. The beta.1 and v0.1.0-beta.3 release manifests, notes,
tags, and assets remain historical and unchanged. Final publication requires
independent P24 release-readiness review and the release workflow.

## Upgrade / rollback

Use a whole-catalog Plugin transition or the beta.2 Installation Kit. For a
reproducible published baseline before beta.2 publication, use the immutable
`v0.2.0-beta.1` or `v0.1.0-beta.3` history as applicable.
