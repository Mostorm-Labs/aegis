## What beta.2 is

Beta.2 is the published prerelease in the Aegis Control Plane v0.2 line,
distributed as one native Plugin with exactly nine canonical Skills. It
materializes the accepted Verification Productization evidence-contract
hardening, Project State v0.6 capability, repository-identity fail-closed
execution, and immutable/append-only historical integration semantics.

## Changes since beta.1

- Project State v0.6 supports `Bound` and affirmative historical `Absent`
  Gate Decision Binding with deterministic v0.5 → v0.6 migration.
- Integrated occurrence identity remains immutable and corroborating evidence
  is append-only.
- Release packaging and exact-nine Plugin parity are bound to the beta.2
  release manifest.

## Boundaries

The repository root `.aegis/**` remains schema v0.5; beta.2 does not claim root
v0.6 persistence or real `int-pr82` persistence. No synthetic or retroactive PR
#82 Gate Decision is created. `SERVICE_PROFILE`, rollout expansion, and a
required daemon/agent/runtime service remain outside the beta.2 product claim.

## Distribution and verification

The published Installation Kit is
`aegis-skill-installation-kit-v0.2.0-beta.2.zip` and contains exactly nine
nested Skill archives. The Release also publishes
`aegis-release-v0.2.0-beta.2.json` and `SHA256SUMS` for reproducible artifact
verification. The beta.1 and v0.1.0-beta.3 release manifests, notes, tags, and
assets remain historical and unchanged.

## Upgrade / rollback

Use a whole-catalog Plugin transition or the published beta.2 Installation Kit.
For rollback or historical reproduction, use the immutable `v0.2.0-beta.1` or
`v0.1.0-beta.3` release boundaries as applicable.
