## Installation

1. Download `aegis-skill-installation-kit-v0.1.0-beta.2.zip` from this Release.
2. Verify it against `SHA256SUMS` if desired.
3. Extract the outer archive once.
4. Upload the nine nested Skill ZIPs to ChatGPT Skills without unpacking those nested ZIPs.
5. Treat any partial Aegis-family catalog as incomplete; normal Multi-Skill use requires the exact nine-Skill catalog.

## Explicit non-goals

This prerelease does **not** claim that Plugin Distribution v0.1 has passed its own P34 product Gate. `aegis-plugin-distribution-v0.1` remains Proposed.

It does not establish:

- one-click Aegis Plugin product acceptance;
- real installed Plugin provenance acceptance;
- whole-catalog Plugin upgrade acceptance;
- Plugin atomic upgrade/fail-closed product acceptance.

Those remain separate Plugin Distribution P34 work. This prerelease remains scoped to the verifiable nine-Skill Installation Kit delivery path.
