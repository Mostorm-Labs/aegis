## Installation

1. Download `aegis-skill-installation-kit-v0.1.0-beta.1.zip` from this Release.
2. Verify it against `SHA256SUMS` if desired.
3. Extract the outer archive once.
4. Upload the nine nested Skill ZIPs to ChatGPT Skills without unpacking those nested ZIPs.
5. Treat any partial Aegis-family catalog as incomplete; normal Multi-Skill use requires the exact nine-Skill catalog.

## Explicit non-goals

This prerelease does **not** claim that Plugin Distribution v0.1 has passed its own P34 product Gate.

It does not provide or claim:

- one-click Aegis Plugin installation;
- real Plugin provenance;
- whole-catalog Plugin upgrade evidence;
- Plugin atomic upgrade/fail-closed acceptance.

Those remain separate Plugin Distribution P34 work. This prerelease is intentionally limited to the already-verifiable nine-Skill Installation Kit delivery path.
