# Aegis v0.1.0-beta.3

Status: **Prerelease — Codex handoff execution-prefix maintenance refresh**

This maintenance prerelease carries the Gate-accepted PR #45 Codex `surface_handoff` execution-prefix semantics onto the published v0.1 line without importing the unreleased Control Plane v0.2 stack.

## Included

- one native Aegis Plugin at version `0.1.0-beta.3` behind the existing repository marketplace source;
- one coherent exact-nine Plugin materialization;
- one `aegis-skill-installation-kit-v0.1.0-beta.3.zip` Release Asset;
- `aegis-release-v0.1.0-beta.3.json` as the standalone release manifest;
- `SHA256SUMS` for the distributable assets.

The repository marketplace source/path remains stable. The Plugin manifest version and exact-nine Skill tree advance together, so an existing GitHub-backed marketplace can exercise the normal whole-catalog `Sync now` update path.

## Changes since v0.1.0-beta.2

- rendered `surface_handoff` envelopes with `preferred_executor: codex` now place the exact execution-trigger instruction immediately before the YAML envelope;
- the prefix remains rendering/trigger metadata only and does not transfer stage ownership, expand Current Authority or package scope, create Evidence, issue a Gate verdict, or mutate Project State;
- canonical, standalone, and native Plugin Skill materializations are synchronized to the accepted semantics;
- the Aegis Plugin manifest advances to `0.1.0-beta.3`, enabling a real GitHub-backed Plugin sync/update observation;
- the nine-Skill Installation Kit and release manifest are refreshed from the same coherent Skill source set;
- the immutable `v0.1.0-beta.2` tag, release manifest, and published assets remain historical and unchanged.

The release workflow reruns Project State, Skillset, generated-distribution, OpenAI Plugin materialization, routing, installed-platform, repository regression, and evaluation checks on the exact release source revision before publishing deterministic assets.

## Plugin sync test

For an existing GitHub-backed Aegis marketplace that follows the repository's maintained default branch:

1. open **Workspace settings** -> **Plugins** -> **Marketplaces**;
2. select the Aegis marketplace;
3. select **Sync now**;
4. confirm that the installed Aegis Plugin resolves the new `0.1.0-beta.3` source set and still exposes the exact nine canonical Skills;
5. exercise a Codex-directed P32 handoff and confirm that the exact execution-trigger prefix appears immediately before the `surface_handoff` YAML envelope.

A marketplace pinned to immutable `v0.1.0-beta.2` is intentionally not expected to advance until its pin is changed.
