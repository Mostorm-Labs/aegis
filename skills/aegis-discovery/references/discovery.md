# Discovery Workflow

## P00 Problem Discovery
Separate symptom, pain, root constraint, and solution proposal. Produce evidence, affected scenario, impact, success criteria, non-goals, and unknowns without choosing architecture.

## P01 Product Research
Separate sourced fact, observation, inference, and assumption. Challenge the problem and compare current alternatives.

## P02 Product Requirement
Define JTBD/scenarios, FR/NFR, priority, acceptance criteria, and explicit out-of-scope, each traceable to value or constraint.

## P03 Capability Traceability
Maintain upstream value and downstream proof, typically `Requirement -> Capability -> Object -> Behavior -> Operation -> Module -> Platform -> Verification`.
