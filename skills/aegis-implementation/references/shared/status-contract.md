# Status Contract

Default statuses: `READY`, `READY_WITH_FINDINGS`, `BLOCKED_AUTHORITY`, `BLOCKED_MISSING_INPUT`, `BLOCKED_UNRESOLVED_DECISION`, `BLOCKED_EVIDENCE`, `BLOCKED_IMPLEMENTATION`, `BLOCKED_ENVIRONMENT`.

Defects: `IMPLEMENTATION_DEFECT`, `SPEC_DEFECT`, `AUTHORITY_CONFLICT`, `MISSING_CONTRACT`, `TEST_DEFECT`, `EVIDENCE_GAP`, `ENVIRONMENT_DEFECT`, `DEPENDENCY_BLOCKER`, `UNRESOLVED_DECISION`.

Gate verdicts: `PASS`, `PASS_WITH_FINDINGS`, `BLOCKED_IMPLEMENTATION`, `BLOCKED_AUTHORITY`, `BLOCKED_EVIDENCE`, `BLOCKED_ENVIRONMENT`.
